# Governed semantic definition checklist — trainee scaffold

Resolve each item from project evidence and accountable human decisions.

## Discover and ground

- [ ] Existing semantic definitions and public marts were searched for reuse/conflict.
- [ ] The source mart is public, contracted, tested, and has a stated grain.
- [ ] The accountable owner and intended consumers are named.
- [ ] Source columns, entities, dimensions, time spine, and installed spec are verified.

## Definition agreement

- [ ] The definition answers a stated business question.
- [ ] Source mart and grain are explicit.
- [ ] Aggregation/formula, filters, time semantics, null behavior, and inclusion policy
      are approved.
- [ ] For brew examples, quality-failure denominator and null-duration treatment are
      explicit.

## Compatibility and governance

- [ ] Existing definitions were checked for reuse, conflict, or migration needs.
- [ ] Consumer and public-interface impact was assessed.

## Implementation and evidence

- [ ] YAML uses the project’s supported format.
- [ ] Parse, semantic validation, scoped mart build, representative query, and owner
      approval are recorded.
